# Project 1 - Empathy Map

## Objective
Understand the needs, behaviors, motivations, and frustrations of busy office professionals before designing a fitness application.

## Deliverables
- Target Audience Definition
- User Personas
- Empathy Map
- UX Research Insights

## Tools Used
- Figma

## Outcome
A clear understanding of user pain points and opportunities for designing a simple and effective fitness experience.
